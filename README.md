# Сборка

Проект собирается автоматически с помощью workflow при ручном запуске (настройки можно менять перед запуском и собирать только конкретные виды результатов)

## Шаг 1: установка библиотек

Для работы с проектом нужен npm и node.

```sh
npm install
```

## Шаг 2: сборка

Перейдите в папку android и запустите Gradle:

```sh
cd android
./gradlew assembleRelease
```
